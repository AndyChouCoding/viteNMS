# Open Vision Vite — Frontend

Vite + React + TypeScript + Tailwind CSS. Renders the network topology graph (Cytoscape.js) and device info panel, wrapped as a desktop app by `../src-tauri`.

```bash
npm run dev     # dev server at http://localhost:5173, expects the backend on http://127.0.0.1:8756
npm run build   # production build to dist/, consumed by the Tauri shell
```

See the repo root `README.md` for overall project context.
